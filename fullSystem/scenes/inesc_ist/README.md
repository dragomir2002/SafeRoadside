# Scene: INESC_IST

A Lisbon plaza filmed from a low static camera, 3840x2160 at 29.97 fps. The
video (Videos/INESC_IST/GX010088.MP4) is not in git.

- map.txt: calibration; the map origin is 38.736741, -9.141845
- points_clicked.csv, calib_check.png: the surveyed points and the fit drawn
  over the image
- road.png, tes.png: the calibration still (frame 3600)
- withguide.png, guide_tracks.txt: tracked vehicle paths (step 2)
- trajetorias.txt, trajetoriasClean.txt: reference trajectories
