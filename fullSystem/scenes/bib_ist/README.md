# Scene: BIB_IST

A Lisbon intersection filmed from an elevated static camera, 3840x2160 at
29.97 fps. The video (Videos/BIB_IST/GX010090.MP4) is not in git.

- map.txt: calibration; the map origin is 38.736407, -9.143549
- road.png, tes.png: the calibration still
- withguide.png, guide_tracks.txt: tracked vehicle paths (step 2)
- trajetorias.txt, trajetoriasClean.txt: reference trajectories
